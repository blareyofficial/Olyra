# Olyra Documentation

**Paid tools, made free.**  
*The technical and project guide to Olyra.*

Welcome to the documentation for [Olyra](https://github.com/blareyofficial/Olyra), an open-access digital tools and browser-games project created by Olyra Foundation.

This documentation explains the project's mission, current architecture, source layout, services, API routes, security model, Cloudflare deployment, local development, and contribution practices. It describes the implementation represented by the repository, not a promise that every planned feature is already shipped.

> **Keep this documentation in sync with the code.** If a route, environment variable, feature, or implementation changes, update the matching page here. Do not document secrets or publish private credentials.

## Project at a glance

| Area | Current implementation |
|---|---|
| Main website | Static HTML, CSS, and browser JavaScript |
| Tool pages | Static HTML with small client-side scripts |
| Server endpoints | Cloudflare Pages Functions under `functions/` |
| Persistent chat storage | Cloudflare KV binding named `CHAT_ROOMS` |
| Chat encryption | Browser Web Crypto API, AES-GCM |
| URL shortener | Olyra endpoint calling the is.gd service |
| QR codes | Generated by an external QR Server endpoint |
| GIF search | Server-side KLIPY API proxy |
| Games rendering | Browser Canvas 2D and DOM controls |
| Gravity simulation | Bounded JavaScript simulation in a Pages Function |
| Build system | No package-based build step is currently defined in the root |

## Important accuracy notes

- Olyra Search currently links to a separately hosted Base44 application. Its internal implementation is not contained in this repository.
- Olyra URL depends on the is.gd URL-shortening service and an external QR-code image service.
- Olyra Chat's server stores encrypted message payloads. The browser holds the room encryption key in the URL fragment, which browsers do not include in ordinary HTTP requests. Anyone with the complete invite link can access the room, so invite links must be treated as secrets.
- The main chat endpoint has an in-memory fallback for local development, but in-memory state is not durable and may disappear when an instance restarts.
- Cloudflare KV is required for shared, persistent chat messages and encrypted attachments across deployed instances.
- The Space Solution simulation is a bounded 2D numerical model. It is not a full astronomical ephemeris, a 3D physics engine, or a guarantee of perfectly conserved energy.
- The documentation distinguishes verified code behavior from deployment settings that must be confirmed in the Cloudflare dashboard.
