# Project overview

## What is Olyra?

Olyra is an open-access collection of online tools and browser games developed by Olyra Foundation. Its tagline is **“Paid tools, made free.”** The project's guiding idea is that useful digital services should be accessible without unnecessary paywalls, subscriptions, advertising, or intrusive data collection.

The home page presents Olyra as an independent nonprofit technology project and communicates these goals:

- Make useful everyday digital tools accessible.
- Keep interfaces straightforward and responsive.
- Avoid unnecessary tracking and advertising.
- Prefer lightweight client-side implementations where appropriate.
- Support keyboard navigation and mobile layouts.
- Treat digital infrastructure as a public good.

These are project goals; they should not be interpreted as a claim that every dependency or third-party service has the same privacy policy as Olyra.

## Main site sections

- **Tools:** Search, URL utilities, and encrypted chat.
- **Games:** A browser-based game library, including arcade, puzzle, multiplayer, and gravity-simulation experiences.
- **SubBrands:** Currently includes a link for LcF, described on the site as a lossless image-compression format.
- **Partners:** Partner names shown by the landing page.
- **Store:** A link to the Olyra Foundation merchandise storefront.
- **Founders:** A page describing the project's founders.

## Current services

### Olyra Search
The repository's `/tools/search/` page links to a separately hosted Base44 application at `https://olyrasearch-app.base44.app`. The search product's application source is not included in this repository, so its internal stack and data handling cannot be established from this codebase alone.

### Olyra URL
A web tool for shortening HTTP/HTTPS URLs. The backend validates the submitted URL and forwards it to is.gd. The interface can also show a QR code generated by a third-party QR-code service. See [Products](products.md) and the [API reference](api-reference.md).

### Olyra Chat
A room-based chat interface that encrypts message payloads in the browser using AES-GCM before sending them to the server. It supports invite links, text messages, GIF search through KLIPY, and encrypted file attachments. Chat uses the `CHAT_ROOMS` KV binding when configured. See [Security](security.md) for important limitations and the threat model.

### Olyra Games
A static game library whose main interaction code lives in `games/games.js`. The current library includes Olyra Drive, Star Catcher, Neon Rush, Block Logic, Orbital Chaos, Maze Breaker, Beat Reactor, Tiny Colony, Pixelbound, Signal Sweep, Bumper Bots, and Space Solution.

The game page renders through Canvas 2D and HTML controls. Space Solution sends bounded simulation requests to a Cloudflare Pages Function at `/api/games/space`.

## Project history and current scope

Olyra has evolved from early no-code prototyping toward a manually maintained HTML/CSS/JavaScript repository deployed through GitHub and Cloudflare Pages. This repository contains the primary site and selected backend functions. Some linked services are hosted externally and must be documented at their own source of truth.

Olyra AI is not part of the current product surface documented here. Do not reintroduce it into menus, service inventories, or setup instructions unless the project owner intentionally brings it back.

## What this project is not

- It is not a single bundled framework application with a compiled frontend.
- It does not contain the implementation of the externally hosted Olyra Search app.
- It does not guarantee anonymity from hosting providers, network operators, or third-party services.
- Its gravity simulator is not intended as a research-grade orbital integrator.
